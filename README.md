# Zanes
This is a Python toolbox for XAS analysis, offering capabilities for data processing, wavelet transform, and fitting. It serves as a wrapper around Xraylarch (https://xraypy.github.io/xraylarch/) and extends its functionality to enable efficient analysis and fitting of thousands of datasets.
